## Sutanu Bhowmick

PhD, Rice University · Senior Data Scientist · Washington, DC

I build methods that recover the parameters of physical models from noisy measurements.

### SNAPE — SimultaNeous basis function Approximation and Parameter Estimation

SNAPE identifies the parameters of ODE and PDE models from measured full-field
response. It never numerically differentiates the data, it does not require the
initial or boundary conditions, and it returns a continuous analytical
approximation of the solution alongside the parameters, with bootstrap
uncertainty bounds.

It recovers the parameters of Burgers' equation from data carrying 100% Gaussian
noise, and identifies a 5th-order Euler–Bernoulli beam model from full-field
video measurements of a vibrating beam.
