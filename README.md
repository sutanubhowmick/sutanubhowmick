### SNAPE — SimultaNeous basis function Approximation and Parameter Estimation

A method I developed for identifying the parameters of ODE and PDE models from measured
full-field response. It never numerically differentiates the data, it does not require
the initial or boundary conditions, and it returns a continuous analytical approximation
of the solution alongside the parameters, with bootstrap uncertainty bounds.

It recovers the parameters of Burgers' equation from data carrying 100% Gaussian noise,
and identifies a fifth-order Euler–Bernoulli beam model from full-field video of a
vibrating beam. It applies wherever a known physical model must be calibrated from noisy
measurements: structural and machine digital twins, medical imaging, grid dynamics, and
thermal characterisation.

**An open-source implementation and interactive demonstrations are in preparation.**
